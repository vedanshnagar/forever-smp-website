# Forever SMP Website

Official static website for **Forever SMP**, designed for Vercel.

## Stack

- HTML
- CSS
- Vanilla JavaScript

No frontend framework, backend, or database is required for this site.

## Repository structure

```text

│   ├── js
```

## Official logo

The official logo is stored at `assets/logo/Forever SMP.png`. Do not rename, move, replace, redesign, or modify this file.

## Confirmed server information

Confirmed values are centralized in `assets/js/site.js` so future sections can reuse the same source of truth without inventing content.
